# UI Requirement Map

## 1. Dashboard

- Menampilkan informasi utama sistem SIKA.
- Menampilkan navigasi menuju halaman Mahasiswa, Dosen, Mata Kuliah, dan KRS.
- Menampilkan ringkasan informasi akademik.

## 2. Mahasiswa

- Menampilkan data mahasiswa.
- Menampilkan NIM.
- Menampilkan nama mahasiswa.
- Menampilkan program studi.
- Menampilkan semester.

## 3. Dosen

- Menampilkan data dosen.
- Menampilkan identitas dosen.
- Menampilkan mata kuliah yang diampu.

## 4. Mata Kuliah

- Menampilkan daftar mata kuliah.
- Menampilkan kode mata kuliah.
- Menampilkan nama mata kuliah.
- Menampilkan jumlah SKS.
- Menampilkan dosen pengampu.

## 5. KRS

- Menampilkan data Kartu Rencana Studi.
- Menampilkan daftar mata kuliah yang diambil mahasiswa.
- Menampilkan jumlah SKS setiap mata kuliah.
- Menampilkan total SKS yang diambil.
- Menampilkan status mata kuliah.
